# Kavinsan Sasikumar — Portfolio

A responsive personal portfolio built with Vite, React and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Production build

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`.

## Deploy

### Vercel

Import the repository in Vercel and use the Vite preset, or configure:

- Build command: `npm run build`
- Output directory: `dist`

### Netlify

Import the repository in Netlify and configure:

- Build command: `npm run build`
- Publish directory: `dist`

Both services detect Vite automatically when importing the project.
